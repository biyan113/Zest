01 / SYSTEM

系统状态，实时可见

CPU、内存压力、磁盘读写、温度与风扇转速。指标来自 macOS 与硬件传感器，不可用时如实显示。

02 / PROCESSES

知道是谁在忙

按应用汇总 CPU 与内存占用。支持排序与快速退出；强制退出前，会再给你一次确认。

03 / MENU BAR

按自己的方式排列

自由选择和拖动 CPU、内存、磁盘、网速、温度与风扇指标。浅色、深色菜单栏都自然融入。
